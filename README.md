 Smart Employee Management System (Smart EMS)

A full-stack Employee Management System built using the MERN stack with AI-powered features to simplify employee management, attendance tracking, leave processing, and performance analysis.

 Overview

Smart EMS is a web-based application designed to streamline HR operations by providing secure role-based access for Admins, HR personnel, and Employees. The system also integrates AI features to assist in decision-making and employee performance evaluation.

---

 Features

### 🔐 Authentication & Authorization
- Secure JWT Authentication
- User Login & Registration
- Password Encryption using bcrypt
- Role-Based Access Control (Admin, HR, Employee)

### 👥 Employee Management
- Add Employees
- Update Employee Details
- Delete Employees
- Department Management
- Employee Profile Management

### 📅 Attendance Management
- Daily Check-in & Check-out
- Working Hours Calculation
- Attendance Tracking
- Monthly Attendance Reports

### 📝 Leave Management
- Apply Leave
- Approve/Reject Leave Requests
- Leave Status Tracking
- Leave History

### 💰 Salary Management
- Generate Salary Slips
- Download Salary Reports
- Salary Details Management

### 📊 Dashboard
- Total Employees
- Attendance Statistics
- Leave Statistics
- Department Overview
- Real-Time Dashboard Analytics

### 🤖 AI Features
- AI Leave Approval Assistant
- AI Employee Performance Analysis
- AI Attendance Prediction
- AI-powered Insights & Recommendations

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/your-username/smart-ems.git
```

## Backend Setup

```bash
cd backend

npm install

npm start
```

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

---

# 🔑 Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```
